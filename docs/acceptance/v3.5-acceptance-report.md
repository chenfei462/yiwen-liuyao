# V3.5 Acceptance Report

## Scope

This report covers the Stage 8 V3.5 operations-readiness baseline:

- Ecosystem quality scoring, risk event creation, and public catalog hiding.
- SLO targets, current latency snapshots, incident records, and incident resolution.
- Commercial readiness gates, simulated billing, and contributor revenue preview.
- Privacy settings, data export, and compliance review resolution.
- Growth and retention metrics for install conversion, content revisits, learning completion, active contributors, review SLA, and complaint handling.
- H5 operations panel for the V3.5 workflows.

## Implemented

- Contract schemas for quality review, risk resolution, incidents, commercial billing simulation, privacy settings, and compliance review resolution.
- In-memory service records with persistence-compatible store keys for V3.5 quality, risk, ops, commercial, privacy, and compliance data.
- API routes for ecosystem quality, risk events, SLO, incidents, commercial readiness, simulated billing, revenue preview, privacy settings, data export, and compliance review queues.
- H5 workbench section for V3.5 operations actions, status summaries, and growth/retention metrics.
- PostgreSQL baseline tables and indexes for V3.5 operations readiness.

## Verification Cases

- Published ecosystem packages start healthy and are visible in the public catalog.
- A quality review can mark a package `needs_review`, create a risk event, and hide it from public package listing.
- Risk events can be resolved with a moderation action and resolution note.
- SLO endpoint reports targets for charting, first AI delta, ecosystem catalog, and submission review.
- Incidents can be created and resolved with mitigation notes.
- Commercial readiness reports blocked real-money gates while keeping sandbox gates available.
- Simulated billing creates a bill preview and contributor revenue preview without real-money movement.
- Ecosystem metrics report install conversion, content revisit count, learning completion count, active contributor count, review SLA P95, and complaint resolution P95.
- Privacy settings can disable history and personalization, request a data export, and generate a compliance review.
- Compliance reviews can be resolved and audited.

## Performance Targets

- Charting P95 target: `< 500ms`.
- First AI explanation chunk P95 target: `< 2s`.
- Ecosystem catalog P95 target: `< 1.5s`.
- Submission review operation P95 target: `< 800ms`.

The deterministic local baseline uses in-process stores and reports placeholder operational metrics through the admin endpoints.

## Compliance Notes

- Quality review notes and compliance review resolutions reject commitment wording.
- Public package listing only includes `published` packages whose quality status is `healthy`.
- Privacy exports explicitly exclude raw question text and private followups.
- Commercial readiness keeps `real_money_movement_enabled = false`.
- Simulated billing and revenue preview do not call real payment, withdrawal, invoice, tax, KYB, or KYC workflows.
