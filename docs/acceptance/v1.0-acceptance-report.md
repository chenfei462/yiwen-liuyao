# V1.0 公开测试验收报告

## 功能验收

- 用户可完成起卦、AI 解读、知识卡学习、练习记录、收藏、标签和脱敏分享。
- `/share/[share_id]` 公开页只读取脱敏分享字段。
- 运营侧可查看反馈、审计日志、知识卡审核状态和指标快照。

## 数据验收

- 术语、知识卡和练习题仅展示 `approved` 内容。
- 知识卡被设为 `rejected` 后，不再出现在前台检索结果中。
- 学习进度、收藏、标签和反馈均支持匿名基线记录。

## 安全验收

- 高风险 reading 不可分享。
- 分享内容不暴露原始问题、用户标识和追问记录。
- 会员权益文案限制为学习与归档，不宣传预测准确性或高风险服务。

## 回归门槛

- `npm test`
- `npm run typecheck`
- `npm run lint`
- `npm run build`

## 剩余风险

- 当前实现仍使用内存加 `.data` 文件存储作为本地开发兜底。
- 后台 v0 未做真实账号权限，仅提供公开测试期的数据与审核接口骨架。
- 支付仅保留权益模型，未接入真实收费。
