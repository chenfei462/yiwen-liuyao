# V1.5 内容化增长验收报告

## 功能验收

- 用户可在 H5 工作台浏览脱敏案例、打开案例事件、开始课程、记录课时进度并获得学习徽章。
- 用户可基于当前 reading 或脱敏案例生成图文提纲、短视频脚本、长图结构和排盘图素材。
- 运营侧可通过接口创建、审核和拒绝案例，并查看实验配置、事件指标和创作者导出数量。
- 实验分组对同一匿名用户保持稳定，关闭实验后回到 `control`。

## 数据验收

- 案例默认只展示 `approved` 状态。
- 案例结论必须回链到 `evidence_ids` 或 `rule_ids`。
- 课程默认只展示 `published` 状态。
- 创作者导出保存来源、素材类型、安全提示和生成时间。

## 合规验收

- 高风险 reading 不可导出传播素材。
- 创作者素材不暴露原始问题、用户标识和私密追问。
- 创作者输出不得包含“包准、改命、消灾、一定复合、一定发财、诊断、投资建议”等承诺词。
- A/B 实验不得绕过安全分类、排盘规则或证据树规则。

## 回归门槛

- `npm test`
- `npm run typecheck`
- `npm run lint`
- `npm run build`

## 剩余风险

- 当前仍使用内存 + `.data/readings.json` 作为本地开发持久化，生产需要换成 PostgreSQL/JSONB。
- 后台接口尚未接入真实账号权限，仅作为公开测试期运营骨架。
- 创作者工具为结构化素材 v0，未接入真实发布平台、版权工作流或收益结算。
