# MVP 0.1 验收报告

## 覆盖范围

- 已实现：问题初始化、风险分类、铜钱摇卦、手动输入、日期/日干支、基础排盘、服务端历史、历史查看和删除。
- 已预留：`/api/readings/analyze` 继续返回占位响应，供 MVP 0.2 接入用神与证据树。
- 未进入本阶段：AI 长解读、追问、课程、分享图、付费、小程序、App、语音、后台管理。

## 自动化验收

- `chart-engine`：覆盖 64 静卦、12 单动爻、12 日干支。
- `contracts`：覆盖合法请求、非法场景、非法爻值、非法日干支。
- `safety`：覆盖医疗、法律、金融、自伤、未成年人、改运消灾、情感控制。
- `reading-service`：覆盖显式日干支、日期推导、服务端历史、脱敏摘要和删除。

## 手动验收口径

1. 打开 H5 首页，输入问题并选择场景。
2. 选择起卦日期。
3. 使用铜钱摇满 6 爻或切换到手动输入。
4. 点击“开始排盘”，结果区应显示本卦、变卦、卦宫、旬空、日干支、起卦日期、六神、六亲和世应。
5. 历史区应显示脱敏摘要，可查看、刷新、删除。
