# MVP 0.2 验收报告

## 覆盖范围

- 已实现：月建输入/推导、Rule Engine v0、用神模板、证据树、反证、安全边界、分析缓存、H5 用神高亮和证据展示。
- 已固化：规则卡种子、PostgreSQL/JSONB schema 基线、`/api/readings/analyze` 结构化响应。
- 未进入本阶段：AI 长解读、流式输出、追问、多轮上下文、RAG 知识库、语音、分享图、课程、付费和后台管理。

## 自动化验收

- `calendar`：覆盖日干支、显式月建、2024-2027 节气表月建和超范围错误。
- `contracts`：覆盖 `month_branch`、`force_refresh`、非法日期范围和基础请求校验。
- `rule-cards`：覆盖 `B-YS`、`B-WR`、`B-DV`、`B-XK`、`B-SY`、`B-HC` 六类规则种子。
- `rule-engine`：覆盖 6 个场景用神模板、动变、旬空反证、证据树字段和高风险拦截。
- `reading-service`：覆盖排盘后分析、证据缓存、强制刷新、安全拦截和历史记录。

## 手动验收口径

1. 打开 H5 首页，输入合规问题并选择场景。
2. 选择 2024-2027 内的起卦日期，使用铜钱或手动输入完成 6 爻。
3. 点击“开始排盘”，结果区应显示本卦、变卦、日干支、月建和基础卦盘。
4. 证据区应显示用神、关键依据、反证、规则编号和来源说明。
5. 输入医疗、法律、投资、自伤、未成年人、改运消灾或情感控制问题时，不应生成规则断语。
