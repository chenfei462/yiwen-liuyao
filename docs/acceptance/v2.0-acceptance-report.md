# V2.0 Acceptance Report

## Scope

本报告覆盖第 6 阶段 V2.0 的最小可验收实现：多端 bootstrap、设备注册、语音任务、导入排盘、社区共学、规则包治理、审核队列和 H5 展示入口。

## Implemented

- Domain contracts：新增 `ClientPlatform`、`VoiceJobStatus`、`ImportSourceType`、`ImportStatus`、`CommunityPostStatus`、`ReviewType`、`RulePackStatus`、`RulePackScope` 等枚举与请求 schema。
- Domain services：新增设备、推送设置、app bootstrap、语音转写/播报、导入排盘、社区帖子/评论/举报、规则包和审核队列服务。
- API routes：新增 V2.0 多端、语音、导入、社区、规则市场和后台审核端点。
- H5 workbench：新增 V2.0 面板，可触发设备注册、语音任务、结构化导入、脱敏共学发布和规则包审核发布。
- Governance：规则包批准前校验专业审核、合规审核和 regression；社区帖子通过审核后才公开。

## Acceptance Checklist

- 多端 bootstrap 返回平台能力、功能开关、安全策略版本和隐私提示。
- 设备注册可生成 `device_id`，推送设置不影响核心安全策略。
- 语音转写复用文本风险分类，高风险语音问题不会进入解读链路。
- 导入排盘生成 `chart_json` 时只使用结构化输入和 Chart Engine，不允许 AI 补造字段。
- 社区公开列表只返回 `published` 内容，举报和待审内容进入审核队列。
- 规则包未通过专业审核、合规审核和标准卦例回归前不能设为 `approved`。
- 运营指标新增设备、语音任务、导入、社区、规则包和 V2.0 P95 延迟字段。

## Verification Commands

最终验收需运行：

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

并执行 HTTP smoke：

- `POST /api/devices/register`
- `POST /api/voice/transcribe`
- `POST /api/readings/import`
- `POST /api/community/posts`
- `POST /api/admin/reviews`
- `POST /api/admin/rule-packs`
- `PATCH /api/admin/rule-packs/[id]`

## Residual Risk

- 当前小程序/App 是 API bootstrap 与壳层契约，未包含真实原生工程。
- 语音实现为文本模拟转写与播报任务，不接入真实 ASR/TTS。
- OCR 仅预留枚举和错误路径，真实图片 OCR 后置。
- 规则包仍使用内存/JSONB 最小存储，正式上线前需要真实权限模型和审核人员账号。
