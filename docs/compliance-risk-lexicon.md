# 合规风险词表与处理策略

## 通用原则

- 结果只用于传统文化学习、娱乐互动和自我反思。
- 不输出确定性现实结论。
- 不输出“必然、保证、包准、改命、消灾、一定复合、一定发财”等承诺式表述。

## 风险标签

| 标签 | 关键词示例 | MVP 0.1 处理 |
| --- | --- | --- |
| `medical` | 癌症、停药、药量、诊断、手术、怀孕 | 拒绝诊断和用药建议，提示就医 |
| `legal` | 坐牢、起诉、判刑、律师、合同纠纷 | 不给法律结论，提示咨询律师 |
| `financial` | 股票、基金、期货、贷款、赌博、投资哪只 | 不给投资建议，提示风险 |
| `self_harm` | 不想活、自杀、轻生、伤害自己 | 触发危机提示，建议联系紧急服务或可信赖的人 |
| `minor` | 未成年、未满18、初中生、小学生 | 限制敏感内容，强调学习属性 |
| `ritual_payment` | 改命、消灾、法事、符咒、包准 | 拒绝相关服务与引流 |
| `relationship_control` | 让他回头、控制他、拆散、挽回包成功 | 不提供控制他人的建议 |

## 当前实现

当前风险分类位于 `src/domain/safety.ts`。MVP 0.1 采用关键词规则，后续 Beta 阶段可升级为规则 + 模型双层分类，但模型输出不能绕过确定性规则。
