# MVP 0.1 衔接计划

## 进入条件

- PRD v1、规则资料基线、API 契约、数据库草案、风险词表已固化。
- Web/H5 脚手架可运行。
- 核心领域测试、类型检查和构建可作为回归门槛。

## 第 1-2 周

- 完善项目脚手架、路由结构和移动端页面骨架。
- 扩充六十四卦标准验收样例。
- 完善问题初始化、起卦输入流程、错误态和空态。

## 第 3 周

- 加固 Chart Engine。
- 对本卦、变卦、卦宫、世应、六亲、六神、旬空增加更多回归测试。
- 把当前内存状态替换为数据库持久化的最小实现。

## 第 4 周

- 完成摇卦页、手动输入页、基础卦盘结果页和历史记录。
- 补齐移动端兼容测试。
- 准备 MVP 0.2 的用神模板、旺衰判断和证据树接口。

## MVP 0.2 接入点

- `/api/readings/analyze` 从占位响应升级为规则证据树。
- `rule_cards` 与 `evidences` 开始持久化。
- AI 只读取 `chart_json + evidence_tree + knowledge_cards`，不直接生成卦盘事实。
